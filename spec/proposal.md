# Proposal: Мини-трекер учебных задач на неделю

## Цель

Создать автономный мини-трекер учебных задач, позволяющий пользователю
добавлять, удалять и отмечать задачи как выполненные, а также отслеживать
затраченное и выполненное учебное время.

Приложение должно быть реализовано в одном HTML-файле
`tracker-v2.html`, содержащем HTML, CSS и JavaScript.

## Границы задачи

### Входит в scope

- Отображение списка учебных задач.
- Добавление новых задач.
- Удаление существующих задач.
- Переключение статуса выполнения задачи.
- Валидация названия и количества часов.
- Фильтрация задач по статусу:
  - Все;
  - Активные;
  - Готовые.
- Подсчет общего количества учебных часов.
- Подсчет выполненных часов.
- Расчет процента выполнения.
- Отображение стартового набора задач.
- Адаптивное отображение интерфейса на экранах шириной 390 px.
- Автономная работа без CDN, внешних библиотек и API-ключей.

### Не входит в scope

- Авторизация пользователей.
- Серверная часть и база данных.
- Синхронизация между устройствами.
- Работа с несколькими пользователями.
- Интеграция с внешними API.
- Дополнительные функции планирования и аналитики.

### Необязательное улучшение

Предусмотреть сохранение задач в localStorage.
Если хранилище недоступно, приложение должно продолжать работу
с данными в памяти и показывать пользователю понятное сообщение.

## Начальные данные

При первом запуске отображаются три задачи:

| Название | Часы | Статус |
|---|---:|---|
| Чтение | 2 | Готово |
| Практика | 4 | Активна |
| Повторение | 2 | Активна |

Начальные показатели:
- Всего: 8 часов.
- Выполнено: 2 часа.
- Прогресс: 25%.

## Ожидаемый результат

Один автономный файл `tracker-v2.html`, содержащий полностью
функциональный мини-трекер учебных задач.
